Detection pipeline

Parse. Validate. Classify. Explain.

Every output is derived from visible fields such as action, threat label, request path, and user agent. No classification depends on an uninspectable probability.

INPUT

CSV or JSON

Normalize a single event into a stable schema and reject missing or invalid controlled values.

RULE ENGINE

Prioritized indicators

Evaluate backup access, traversal, privilege, upload, injection-tool, login, and scanning patterns.

AUDIT OUTPUT

Reason + controls

Return the attack type, the triggering explanation, a score, severity, and mapped controls.
